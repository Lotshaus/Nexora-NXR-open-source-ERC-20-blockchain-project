# Security Policy

## Security Status

Nexora is an experimental Ethereum Sepolia testnet project.

The smart contract has not been independently audited and should not be considered production-ready financial software.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately through GitHub Security Advisories when available.

Please do not publicly disclose sensitive vulnerability details before the issue has been investigated.

## Scope

Security reports may include:

- Smart-contract vulnerabilities
- Access-control issues
- Unexpected token behaviour
- Website security issues
- Infrastructure issues

## Testnet Warning

Nexora currently operates on Ethereum Sepolia.

NXR has no intended real-world monetary value.
