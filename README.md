# 🟣 About

**Nexora (NXR)** is an open-source experimental ERC-20 token project built on Ethereum.

The project is focused on learning and experimenting with:

* Ethereum smart contracts
* ERC-20 tokens
* Web3 development
* Wallet integration
* Blockchain explorers
* Tokenomics
* DApp development
* Open-source software development

Nexora is currently deployed exclusively on the **Ethereum Sepolia testnet**.

# 🔐 Security

Security is an important part of the Nexora development process.

The project aims to:

* Keep the smart contract simple and auditable
* Use established OpenZeppelin implementations
* Avoid unnecessary privileged functionality
* Test contracts on Sepolia before considering further deployment
* Verify deployed contracts on blockchain explorers
* Document contract changes
* Perform security reviews before any potential future mainnet deployment

> Nexora has **not** been independently audited. Do not treat the project as production-ready financial software.

### Reporting a Vulnerability

If you discover a potential security vulnerability, please **do not publicly disclose sensitive details before the issue can be reviewed**.

Create a private security report through the repository's available GitHub security features when available.
